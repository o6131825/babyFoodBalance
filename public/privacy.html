Политика конфиденциальности

Приложение babyfood-balance. Дата обновления: 2 сентября 2026.

Эта страница описывает, какие данные обрабатывает приложение babyfood-balance (далее — «приложение»), доступное по адресу https://babyfood-balance.vercel.app.

Кто обрабатывает данные

Приложение работает в браузере пользователя и не имеет собственного сервера и базы данных. Разработчик не получает копии ваших данных о детях, питании или файлов с Google Диска.

Какие данные обрабатываются

  • Данные аккаунта Google: имя, адрес электронной почты и фото профиля — чтобы показать, кто вошёл.
  • Токен доступа Google — чтобы синхронизировать данные с вашим Google Диском. Токен хранится только в браузере на вашем устройстве.
  • Данные приложения: дети, категории питания, лимиты и остатки. Они сохраняются в скрытой папке приложения на вашем Google Диске (Google Drive application data folder) и при необходимости в памяти браузера на устройстве.

Приложение не запрашивает доступ ко всем файлам Google Диска: только к своей служебной папке.

Зачем это нужно

Данные используются только для входа, учёта остатков детского питания и синхронизации между вашими устройствами. Мы не используем данные для рекламы, аналитики сторонних сервисов или продажи третьим лицам.

Передача третьим лицам

Для входа и хранения используется Google (вход через Google и Google Drive). Обработка этих данных также регулируется политикой конфиденциальности Google. Разработчик приложения не передаёт ваши данные другим компаниям.

Хранение и удаление

  • В настройках приложения можно удалить все данные из служебной папки Google Диска. После этого копия на этом устройстве тоже сбрасывается, чтобы данные не загрузились обратно.
  • Выйти из аккаунта можно в настройках приложения: локальный токен удаляется с устройства.
  • Доступ приложения к Google можно отозвать в настройках аккаунта Google: https://myaccount.google.com/permissions.

Дети

Приложение предназначено для родителей и опекунов. Сведения о детях вводит сам пользователь и хранит в своём Google-аккаунте. Мы не собираем данные детей на своих серверах.

Контакты

Вопросы по этой политике можно задать через контактный email разработчика, указанный на экране согласия Google при входе в приложение.
